# Supported formats

Generated by `scripts/formats.py` from `retro-image --list-formats`.
Do not edit by hand.

531 formats on 51 platforms.

A format marked under Detected has a signature, so it is also recognised
by content when the file has some other name. One marked under Companions
can pick up extra data, usually the palette, from a file next to it with
the same base name.

See [coverage.md](coverage.md) for a comparison with RECOIL's format list.
